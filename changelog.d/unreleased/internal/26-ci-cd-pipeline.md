- **One CI/CD pipeline gated by `Checks`.** `ci.yml` becomes `ci-cd.yml`: jobs run only for the domains a change touches, `Checks` is the one required status, and CD runs after it on main. The Linux binaries are built once, and the image copies them in and the release attaches them; the image is pushed under its commit while the checks run and retagged afterwards, and macOS takes one runner, only for dependency, manifest or toolchain changes and for releases.
