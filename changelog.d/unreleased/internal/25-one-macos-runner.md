- **CI takes at most one macOS runner per run, and usually none.** The account's macOS runners are few and shared across repositories, so queued macOS jobs held up every other project's CI. The Apple build is a single `macOS aarch64` job that runs clippy, the tests and the release build in one target dir. A pull request runs it only when it changes the toolchain, dependencies or workflows, since the crate has no platform-specific code and Linux checks the rest; on main it runs only for a release, where it builds, signs and packages the binary.
